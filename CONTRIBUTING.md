# Contributing to The Soundboard

Contributions are welcome from everyone. The repository follows a fork-and-pull-request workflow:

1. Fork the repository and create a focused branch from `master`.
2. Make the change in the existing project style.
3. Add or update tests when behavior changes.
4. Run `./gradlew check` on Linux or macOS, or `.\gradlew.bat check` on Windows.
5. Open a pull request against `master` and complete the verification checklist.

CI checks the project on Windows, Linux, and macOS. All files are owned by `@Arkanium77`; a code-owner review and passing required checks are needed before a pull request can be merged. Only the repository owner merges changes into `master`.

Keep pull requests small enough to review as a single change. Do not include build output, IDE state, imported skins or localizations, project libraries, or other user data.

By contributing, you agree that your contribution may be distributed under the repository's [MIT License](LICENSE).
