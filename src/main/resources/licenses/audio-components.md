# Audio component sources

- libvorbis and libogg: https://xiph.org/ (BSD-style).
- libopus and libopusfile: https://opus-codec.org/ (BSD-style).
- VorbisSPI: https://github.com/umjammer/vorbisspi (LGPL-2.1-or-later).
- jFLAC: https://github.com/nguillaumin/jflac (LGPL-2.1-or-later).
- Concentus 1.0.2 Java distribution: https://github.com/jaredmdobson/Concentus (BSD-3-Clause); original
  implementation: https://github.com/lostromb/concentus. The original license is included alongside this file.
- VorbisJava 0.8 Ogg reader: https://github.com/Gagravarr/VorbisJava (Apache-2.0).

- gst1-java-core 1.4.0: https://github.com/gstreamer-java/gst1-java-core/tree/v1.4.0 (LGPL-3.0).
  The binding is unmodified; LGPL-3.0 and its incorporated GPL-3.0 text accompany this file.
- JNA 5.18.1: https://github.com/java-native-access/jna/tree/5.18.1 (used under Apache-2.0).
